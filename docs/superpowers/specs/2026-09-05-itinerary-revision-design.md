# Tokyo with me — 일정 재정비 설계

작성일: 2026-09-05  
여행일: 2026-09-12(토) ~ 09-15(화), 3박 4일

> 이 문서는 `2026-08-15-tokyo-with-me-design.md`의 여행 일정·맛집·카페 데이터만 대체한다. 앱의 단일 HTML, 장소 단일 정의, GPS 거리순 카페, 로컬 우선 상태 구조는 유지한다.

---

## 1. 결정 사항

- **긴자 핫포(銀座八芳)는 제외한다.** 일정, 맛집 후보, 지도 핀에서 모두 삭제한다.
- Day 1은 아사쿠사가 아니라 **롯폰기 → 긴자 → 니시아자부** 동선이다.
- Day 2는 **디즈니씨 → 아사쿠사**다. 유라쿠초·긴자 쇼핑과 신바시 가드시타 일정은 제거한다.
- Day 3은 **F45 → 시바공원 → 하라주쿠·오모테산도·시부야 → 시부야 스카이 → 다이칸야마 타블로스 라운지**다.
- Day 3 신주쿠는 고정 일정에서 제거한다. 시부야 스카이 후 신주쿠를 들렀다가 다이칸야마으로 이동하면 불필요한 역방향 이동이 생긴다.
- Day 4는 **FLEX DAY**다. 신주쿠·마지막 쇼핑·카페는 현장 선택이며, 나리타행 이동 시각만 고정한다.
- **카나데 라운지(KANADE LOUNGE)**를 Day 1 고정 카페로 둔다. 가조엔 도쿄 1층(메구로구 시모메구로 1-8-1), 10:30–22:30, 라스트오더 21:30, 무휴·예약 가능이다.

## 2. 최종 4일 골격

### Day 1 — 09/12 (토) · 도착 + 롯폰기 + 긴자

| 순서 | 일정 | 데이터 처리 |
|---|---|---|
| 1 | 나리타 도착 → 입국·수하물 → 액세스특급 신바시 | 기존 공항 이동 유지 |
| 2 | 칸데오 신바시 캐리어 보관 | 기존 숙소 장소 유지 |
| 3 | 점심 | `긴자 텐류 / 긴자 오보로즈키 / 쿄스시 / 백화점 식당가`를 맛집 후보로 표시. 확정 선택 없음 |
| 4 | 카나데 라운지 | 고정 카페. 가조엔 도쿄 1층(메구로) · 10:30–22:30 · 예약 가능 |
| 5 | 론 뮤엑 전시, 모리미술관 | 고정 장소. 9/12 토요일 09:00–22:00, 최종 입장 21:30 |
| 6 | 긴자 웨스트 본점 | 고정 카페. 긴자 7-3-6 |
| 7 | 긴자 구경·쇼핑 | 고정 지역 카드 |
| 8 | 곤파치 니시아자부 | 고정 저녁 장소 |
| 9 | 숙소 복귀 | 신바시 숙소 |

모리미술관은 마감이 늦어 도착일에도 시간 압박이 낮다. 점심은 나리타 도착 시각·입국 대기·카나데 라운지 체류 시간이 확정된 뒤 후보 중 선택한다.

### Day 2 — 09/13 (일) · 디즈니씨 + 아사쿠사

| 순서 | 일정 | 데이터 처리 |
|---|---|---|
| 1 | 오전 디즈니씨 입장 | 전용 작전판 유지 |
| 2 | 파크 내 점심·간식 | 디즈니씨 식사 후보 유지 |
| 3 | 16:00 전후 퇴장 | 고정 앵커 |
| 4 | 아사쿠사 이동 | Day 2 지도 핀을 아사쿠사로 변경 |
| 5 | 센소지·나카미세·아사쿠사 골목 | 고정 관광 슬롯 |
| 6 | 아사쿠사 길가 술집 | 특정 업소 미확정. `골목 탐색` 카드로 표시 |
| 7 | 숙소 복귀 | 신바시 숙소 |

디즈니씨 공식 운영시간은 09:00–21:00이며, 16시 퇴장은 의도적이다. 파크 내 식사로 시간을 아끼고, 저녁의 분위기는 아사쿠사 골목에서 현장 선택한다.

### Day 3 — 09/14 (월) · 운동 + 쇼핑 + 시부야 + 다이칸야마

| 순서 | 일정 | 데이터 처리 |
|---|---|---|
| 1 | F45 Training Hamamatsucho | 수업 시간은 예약 후 입력. 장소 고정 |
| 2 | 시바공원 쁘띠 피크닉 | 고정 휴식 슬롯 |
| 3 | Stüssy Harajuku | 쇼핑 고정 |
| 4 | Maison Kitsuné Aoyama | 쇼핑 고정 |
| 5 | Barbour Harajuku Cat Street | 쇼핑 고정 |
| 6 | 시부야 쇼핑 | 고정 지역 카드 |
| 7 | 시부야 스카이 | 일몰 시간대, 사전 예약 필요 |
| 8 | 타블로스 라운지, 다이칸야마 | 고정 마무리 장소 |

Stüssy(19시), Barbour·Maison Kitsuné(20시)의 영업 종료 전에 낮~오후 쇼핑을 집중한다. 타블로스 라운지는 20:00–02:00이므로 시부야 스카이 후 이동이 자연스럽다. **신주쿠는 이 날의 고정 일정에서 제외한다.**

### Day 4 — 09/15 (화) · FLEX DAY + 귀국

| 순서 | 일정 | 데이터 처리 |
|---|---|---|
| 1 | 체크아웃·숙소 짐 보관 | 고정 |
| 2 | FLEX DAY | `신주쿠 / 마지막 쇼핑 / 카페 / 그날 가고 싶은 곳` 선택 카드 |
| 3 | Gransta Tokyo | 마지막 선물·식사 후보 |
| 4 | 신바시 숙소 짐 픽업 | 고정 |
| 5 | 15:00 전후 신바시 출발 | 고정 마감 카드 |
| 6 | 16:00 전후 나리타 도착 | 고정 마감 카드 |
| 7 | 18:30 출국 | 고정 |

이 날은 장소를 강제하지 않는다. 대신 앱에서 `15:00 신바시 출발`을 강한 경고로 표시해 비행기 리스크를 막는다.

## 3. 맛집·카페 탭 변경

### 맛집 탭

각 장소는 일정의 확정 식사와 분리해 **지역별 후보**로 보여준다. 후보를 골라도 일정 자체가 바뀌지는 않는다.

| 지역 | 추가 후보 | 비고 |
|---|---|---|
| 긴자 | 긴자 텐류, 긴자 오보로즈키, 쿄스시, 백화점 식당가 | Day 1 점심 후보 |
| 아오야마·오모테산도 | 토라후쿠 아오야마 본점 | Day 3 쇼핑 중 식사 후보 |
| 아사쿠사 | 아사쿠사 길가 술집 | 가게명 대신 골목 탐색 가이드 |
| 나카메구로 | 야키니쿠 사이몬 | 일정 바깥 후보. 이번 일정에 강제 삽입하지 않음 |
| 칸다 | 키칸보 | 일정 바깥 후보. 이번 일정에 강제 삽입하지 않음 |
| 신주쿠 | 카메야 | Day 4 FLEX 후보 |

에와타리 과자 도매점(긴시초), 페니 레인(키치죠지), 아울렛은 이번 일정에서 제외한다.

| 지역 | 추가 장소 | 쓰임 |

## 4. 화면·데이터 변경

### 일정 데이터

- `DAYS[0]`에서 긴자 핫포·아사쿠사·스미다강 슬롯을 제거하고 Day 1 새 동선으로 교체한다.
- `DAYS[1]` 퇴장 후 유라쿠초·긴자 쇼핑·신바시 가드시타 슬롯을 아사쿠사·센소지·골목 탐색 슬롯으로 교체한다.
- `DAYS[2]` 저녁 신주쿠 슬롯을 제거하고 다이칸야마 타블로스 슬롯을 추가한다.
- `DAYS[3]`는 정해진 장소 나열이 아닌 FLEX 카드 묶음으로 구성한다. 단, 숙소 짐 픽업·15시 출발·16시 나리타·18:30 출국은 일반 타임라인 고정 슬롯이다.

### 장소 데이터

- 긴자 핫포 `P.happo`와 `FOOD`의 해당 후보를 삭제한다.
- 모리미술관, 긴자 웨스트, 곤파치 니시아자부, 시바공원, Stüssy Harajuku, Maison Kitsuné Aoyama, Barbour Harajuku Cat Street, 타블로스 라운지, Gransta Tokyo를 장소 데이터에 추가한다.
- 카나데 라운지는 일반 장소 데이터로 추가한다. 좌표·구글맵 길안내·영업시간·예약 링크를 제공한다.

### 지도

- 날짜별 `pins`는 그날의 실제 확정 장소만 보여준다.
- Day 4의 FLEX 후보는 지도 핀에 강제 추가하지 않는다. 후보 카드의 지도 링크로만 연다.

## 6. 검증 기준

- 긴자 핫포·유라쿠초 쇼핑·신바시 가드시타가 신규 일정·맛집·지도에서 남아 있지 않는다.
- 모든 확정 장소는 일정 카드와 지도에서 같은 장소 데이터를 쓴다.
- 카나데 라운지는 좌표 기반 지도 핀·길안내 링크와 영업시간을 가진다.
- Day 4는 FLEX 카드가 있어도 15시 신바시 출발 경고가 항상 노출된다.
- Day 3에 신주쿠 고정 슬롯이 없고 타블로스 라운지 슬롯이 있다.
